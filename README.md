# 엘리멘트리 — 파편 전투 초안 0.5

루이·동생 루인, 자객 제인과 두 부하, 형제의 스킬과 파편 기본 규칙은 사용자 설정입니다. 전투 장면과 대사, 체력·피해량, 적 스킬·행동 방식, 턴 순서, 암흑 분배의 세부 처리는 **임시 설정**입니다. 세계관 프롤로그는 게임에 출력하지 않습니다.

## 실행하기

1. GitHub에서 Code → Download ZIP으로 받습니다.
2. 압축을 풀고 **`엘리멘트리.html`**을 더블클릭합니다.
3. 제목 아래에 **파편 전투 버전 0.5**가 보이면 최신 버전입니다.

직접 대사나 수치를 바꾸려면 `data.js`를 수정하고 **`index.html`**을 열어 새로고침하세요. 이 방식은 나머지 파일도 같은 폴더에 있어야 합니다. `엘리멘트리.html`은 만들어진 시점의 내용을 담은 단일 파일입니다.

계정·API 키·설치는 필요 없습니다. 개발 환경에서는 저장소 폴더에서 `python3 -m http.server 8000 --bind 127.0.0.1`로 실행하고 Ctrl+C로 종료할 수 있습니다.

## 전투하는 방법

- 대화 → 준비 선택 → 전투 시작 순서로 진행합니다.
- 임시 턴 순서: **루이 → 루인 → 제인 → 오른팔 → 왼팔**. 전투 불능 인물은 건너뜁니다.
- 아군 턴에는 **적 카드를 눌러 대상 선택 → 공격 또는 스킬 버튼**을 누릅니다.
- 적 턴은 버튼 없이 **자동 진행**합니다. 각 행동의 기록이 한 글자씩, 한 줄씩 출력된 뒤 다음 인물로 넘어갑니다. 출력 중에는 추가 행동이 잠기며 스페이스바로 현재 행동의 기록을 즉시 표시할 수 있습니다.
- 파티 컷 아래와 적 카드의 **작은 게이지**로 각자의 파편을 확인합니다. 하단 큰 파편 게이지는 제거했습니다.
- 피해를 받으면 체력 게이지가 불빛과 함께 서서히 줄어듭니다. 동작 줄이기 설정에서는 애니메이션을 생략합니다.
- 적 전원 전투 불능이면 승리, 형제 모두 전투 불능이면 패배입니다. 결과 화면에서 다시 시작할 수 있습니다.

## 파편 규칙

- 모든 인물은 **0/5**에서 시작합니다.
- 기본 공격으로 **1 회복**, 최대 **5**입니다. 적도 같은 규칙입니다.
- 스킬은 정해진 코스트를 소모합니다. 방어는 회복하지 않습니다.
- **초과 사용은 현재 보류**입니다. 파편이 부족한 스킬은 버튼이 비활성화됩니다.
- 나중에 초과 사용을 허용하면, 지정 스킬을 파편 부족 상태에서 사용 시 게이지는 0이 되고 **파편화로 다음 자신의 두 턴 동안 회복이 금지**됩니다. 다른 인물의 턴에는 기간이 줄지 않습니다.
- 이 향후 규칙은 엔진 검증까지 준비되어 있지만 실제 게임에서는 `COMBAT.rules.enableOverdraw: false`라 발동하지 않습니다. 허용하려면 전체 플래그와 해당 스킬의 `allowOverdraw: true`가 모두 필요합니다. 지정되지 않은 스킬은 허용되지 않습니다.

## 형제의 스킬

| 인물 | 기술 | 코스트 | 효과 |
| --- | --- | --- | --- |
| 루이 | 그라비티 볼 | 기본 공격, 회복 1 | 적 하나에 피해 + 암흑 1 |
| 루이 | 그라비티 폴 | 1 | 암흑이 있는 모든 적의 스택을 각각 소진하고 스택당 피해 |
| 루이 | 그라비티 체이스 | 1 | 암흑이 있는 적 하나의 스택을 생존 적 전체에 분배 |
| 루인 | 어둠을 밝히는 빛 | 기본 공격, 회복 1 | 적 하나에 피해 + 광채 1 |
| 루인 | 어둠을 가르는 빛 | 1 | 적 하나에 피해 + 광채 3 |

**임시 세부 처리:** 체이스는 선택한 적도 분배 대상에 포함합니다. 선택한 적의 스택만 걷어 분배하고 다른 적의 기존 스택은 보존합니다. 모든 생존 적에게 최소 1스택을 부여하므로, 원본이 1스택이어도 생존 적 3명에게 각각 1스택이 생깁니다. 그 이상일 때 추가분은 균등하게 나누고, 나머지는 제인 → 오른팔 → 왼팔 순으로 배분합니다. 죽은 적은 제외합니다. 폴은 표식이 있는 적 전원을 자동으로 타격하며, 선택한 카드와 무관합니다. 광채의 추가 효과는 아직 없고 누적만 표시합니다.

기본 방어는 다음 자신의 턴까지 받는 피해를 75% 감소시킵니다(소수점 올림). 피해량과 체력, 공격 준비 선택 보너스는 모두 임시입니다. 제인의 체력은 두 부하보다 많으며, 임시 자객 스킬로 급소 찌르기와 그림자 습격을 사용합니다. 적은 자신의 코스트를 확인하고 부족하면 기본 공격을 합니다.

## 데이터 바꾸기

`data.js`에서 이야기와 수치를 관리합니다. 따옴표와 쉼표를 유지하며 바꾸세요.

| 바꿀 것 | 위치 |
| --- | --- |
| 제목·대사·선택지·승패 이야기 | `STORY` |
| 파티 이름·체력·스킬 | `COMBAT.party` |
| 적 이름·체력·스킬·행동 패턴 | `COMBAT.enemies` |
| 기술 피해 | 각 스킬의 `damage` 또는 `damagePerStack` |
| 기술 코스트·부여 스택 | 각 스킬의 `cost`, `status`, `stacks` |
| 시작 코스트·회복량·파편화 기간 | `COMBAT.rules` |
| 타이핑·자동 진행 속도 | `PRESENTATION` |

인물 `id`와 스킬 `id`는 내부 연결용 이름이며 중복되지 않아야 합니다. 단일 파일 버전 갱신은 `python3 tools/build_standalone.py`로 합니다.

## 대화 조작

- 타이핑 중 **스페이스바**를 누르면 현재 화면의 이야기 전체가 표시됩니다.
- 다음 버튼은 출력 중에는 전체 표시, 출력 후에는 다음 대화로 이동합니다.
- 우상단 **스킵**은 빠르게 넘기고, **자동 진행**은 출력 후 잠시 기다렸다가 넘깁니다. 다시 누르면 중지합니다.
- 선택지와 전투에서는 멈추며, 결과 화면을 자동으로 재시작하지 않습니다.
- **돌아보기**는 이번 플레이에서 만난 이야기입니다. 열어 두면 이야기·전투 출력과 적 자동 진행이 멈추고 닫기/Esc로 이어갑니다.
- 재시작·새로고침 시 진행과 회고는 초기화됩니다.

## 검증

- `node tests/battle.test.cjs`: 0 시작, 양측 코스트, 스택·범위·분배, 대상 제약, 사망자 건너뛰기, 향후 파편화의 정확한 두 턴, 승패와 실제 전투 완주를 검증합니다.
- 개발용 Playwright·Chromium이 있으면 로컬 서버를 켠 뒤 `node tests/story-ui.test.cjs`로 화면 조작, 적 자동 진행, 회고 중 일시 정지, 체력 연출과 체이스 전체 확산을 확인합니다. Chromium 경로는 `CHROMIUM_PATH`, 검사할 게임 주소는 `GAME_URL`로 지정할 수 있습니다.
- 게임 실행에는 검증 도구가 필요 없습니다. 이 클라우드 브라우저는 `file://`를 차단하므로 브라우저 검증은 로컬 서버로 진행합니다.

초상·파편 모양은 임시입니다. 저장 기능, 여러 전투, 이미지·음악 연출은 아직 없습니다.
