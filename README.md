# 엘리멘트리 — 스토리 게임 초안

제목은 **엘리멘트리**입니다. 모든 인물, 이야기, 장소는 **임시 설정**입니다. 원작 자료를 받은 뒤 교체할 수 있습니다.

## 실행하기 (설치 불필요)

1. 이 폴더의 파일들을 컴퓨터에 내려받습니다.
2. `index.html`을 더블클릭해 Chrome, Edge, Firefox 등의 브라우저로 엽니다.
3. 대화를 읽고 → 준비 선택 → 전투 → 결과까지 플레이합니다.

파일들이 같은 폴더에 있어야 합니다. 별도 계정, 서버, API 키가 필요 없습니다.

개발 환경에서는 저장소 폴더에서 `python3 -m http.server 8000 --bind 127.0.0.1`로 로컬 서버를 실행해도 됩니다. 종료는 Ctrl+C입니다.

## 플레이 방법

- **공격**: 적에게 피해를 줍니다. 검을 선택하면 공격력이 올라갑니다.
- **방어**: 그 턴 받는 피해를 75% 줄입니다(소수점은 올림). 적의 강한 일격 전에 유용합니다.
- **새벽의 빛 (스킬)**: 큰 피해를 주며 전투당 2번 사용합니다.
- 한 행동마다 적이 반격합니다. 적을 먼저 쓰러뜨리면 반격하지 않습니다.
- 적은 매 3번째 턴에 강한 일격을 사용하며 화면에 다음 행동이 표시됩니다.
- 결과 화면에서 처음부터 다시 플레이할 수 있습니다.

## 내 소설로 교체하기

`data.js`만 먼저 열어 보세요. 따옴표와 쉼표를 유지하면서 내용을 바꾸면 됩니다.

| 바꿀 것 | 위치 |
| --- | --- |
| 제목, 인물 대사, 장면 | `STORY.title`, `STORY.dialogue`, `STORY.sceneTitle` |
| 선택지와 선택 이후 이야기 | `STORY.choices` |
| 전투 시작, 승리·패배 이야기 | `STORY.encounter`, `STORY.victory`, `STORY.defeat` |
| 체력, 공격력, 스킬 횟수·피해 | `COMBAT.player`, `COMBAT.enemy` |
| 강한 공격 주기, 방어 효과 | `COMBAT.enemy.heavyEvery`, `COMBAT.defenseMultiplier` |

`battle.js`는 전투 규칙, `game.js`는 화면 진행, `style.css`는 디자인입니다.
현재 선택지는 공격력/체력 보너스를 지원합니다. 체력과 피해는 양의 정수, 스킬 횟수는 0 이상의 정수, 강한 공격 주기는 1 이상의 정수, 방어 배율은 0~1로 설정하세요.

첫 버전에는 저장 기능, 여러 전투, 이미지·음악, 원작 설정은 포함하지 않았습니다. 재시작하거나 새로고침하면 진행이 초기화됩니다.

## 기본 검증

Node.js가 있는 개발 환경에서 `node tests/battle.test.cjs`를 실행하면 공격·방어·스킬 제한, 선택 보너스, 승패 판정이 검증됩니다.

검증 결과: 전투 규칙 5개 검증 통과. 실제 Chromium에서 로컬 서버로 대화 → 선택 → 전투 → 승리/패배 → 다시 시작, 스킬 소진, 모바일 가로 넘침 없음과 JavaScript 오류 없음 확인. 이 클라우드 브라우저는 `file://` 접근을 정책으로 차단하므로 파일 더블클릭 방식은 이 환경에서 직접 검증하지 못했습니다. 외부 요청 없이 상대 경로로 파일을 읽는 구성입니다.


## 텍스트와 회고 조작

- 이야기는 한 글자씩 출력됩니다. **스페이스바**로 현재 화면의 이야기 전체를 즉시 표시합니다.
- 다음 버튼을 출력 중 누르면 먼저 전체 표시하고, 한 번 더 누르면 다음 대화로 진행합니다.
- 우상단 **스킵**은 대화를 빠르게 넘기며, **자동 진행**은 출력 완료 후 잠시 기다렸다가 넘깁니다. 다시 누르면 중지합니다.
- 두 기능은 선택지와 전투에서 멈춥니다. 선택 후 이야기에서는 다시 켤 수 있습니다. 결과 화면은 자동으로 재시작되지 않습니다.
- **돌아보기**는 이번 플레이에서 만난 이야기를 표시합니다. 회고창을 연 동안 출력과 자동 진행이 멈추며, 닫기 또는 Esc로 이어갑니다.
- 다시 시작하면 회고도 초기화됩니다. 새로고침 이후에는 보존되지 않습니다.
- `data.js`의 `PRESENTATION`에서 타이핑 속도와 자동·스킵 대기 시간을 바꿀 수 있습니다.

텍스트 조작 검증: 개발 환경에 Playwright와 Chromium이 있으면 로컬 서버를 켜고 `node tests/story-ui.test.cjs`로 확인합니다. Chromium 경로는 `CHROMIUM_PATH`로 지정할 수 있습니다. 게임 실행 자체에는 이 도구들이 필요하지 않습니다.
